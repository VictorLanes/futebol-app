# Craque Manager ⚽

Jogo de futebol para Android: você é **técnico e presidente**.

- **Partidas com joystick** (visão de cima): passe, lançamento, chute com força, correr, carrinho e troca de jogador.
- **Carreira**: comece na Série C do seu estado e suba até a Série A.
- **Competições**: estadual, Liga Nacional (Séries A, B e C com acesso e rebaixamento), Copa Nacional, Copa das Américas de Clubes e Copa dos Campeões Mundial.
- **Clube**: estádio, centro de treinamento e categoria de base (10 níveis cada), preço do ingresso e finanças.
- **Elenco**: escalação por formação, mercado de transferências, vendas com negociação, evolução e aposentadoria dos jogadores.

Clubes, jogadores e torneios são fictícios. O APK é gerado pelo GitHub Actions e fica na aba **Releases**.
